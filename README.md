# single-cell-atlas-explorer — PBMC3k Scanpy analysis pipeline

A reproducible single-cell RNA-seq analysis of the classic **10x Genomics
"3k PBMCs from a Healthy Donor"** dataset (2,700 cells × 32,738 genes) using
[Scanpy](https://scanpy.readthedocs.io/): **quality control → normalization →
dimensionality reduction → clustering → cell-type annotation**, packaged as a
notebook-plus-script pair with a Nextflow/Docker/MultiQC wrapper.

## Stack and rationale

| Layer | Tool | Role |
|---|---|---|
| Analysis | **Scanpy** (Python) | QC, normalization, PCA/UMAP, Leiden clustering, marker genes, annotation |
| Orchestration | **Nextflow** (DSL2) | Reproducible, resumable, step-wise pipeline (`nextflow/main.nf`) |
| Environment | **Docker** | Containerized, pinned environment (`docker/Dockerfile`) |
| Reporting | **MultiQC** | One HTML report aggregating step-wise QC metrics & composition |

> **Note on the suggested stack (GATK, SAMtools/BCFtools):** this dataset is
> already an expression matrix (barcodes × genes), not raw sequencing reads —
> there are no FASTQ files to align or call variants on. GATK and
> SAMtools/BCFtools are therefore **not applicable** to the Scanpy workflow
> (they target bulk short-read variant calling), so they are intentionally
> omitted. Nextflow, Docker and MultiQC are excellent fits and are used as
> suggested; MultiQC here aggregates Scanpy-specific custom content rather than
> alignment statistics.

## Quickstart

### 0. Prerequisites

* Python ≥ 3.12 with the packages in `docker/requirements.txt`
  (or `conda env create -f environment.yml`), plus Jupyter for the notebook.
* [Nextflow](https://www.nextflow.io/) (≥ 23.10, needs Java 17+).
  No launcher installed? `curl -s https://get.nextflow.io | bash` drops one in
  the current directory.
* Docker (only for the `docker` profile) — start the daemon first.

### 1. Download the data

```bash
python obtain_dataset.py --output data/pbmc3k_raw.h5ad
```

### 2. Run the analysis as a script

```bash
python analysis/pbmc3k_scanpy.py --input data/pbmc3k_raw.h5ad --outdir results --step all
# or step by step (each step reads the previous step's h5ad):
python analysis/pbmc3k_scanpy.py --input results/objects/qc.h5ad --outdir results --step normalize
```

### 3. Explore the executed notebook

```bash
jupyter notebook analysis/pbmc3k_scanpy.ipynb
```

The notebook is already executed (figures + tables inline) and ends with a
short biological interpretation. It calls the exact same functions as the
script — regenerate it any time with
`python tools/build_notebook.py`.

### 4. Run the Nextflow pipeline

Local execution (uses whatever `python3` is on your `PATH`; override with
`--python`):

```bash
export NXF_HOME="$PWD/.nextflow_home"        # optional: keep Nextflow's cache in-repo
nextflow run nextflow/main.nf -profile standard --python "$PWD/.venv/bin/python"
```

Containerized execution (build the image once, then run):

```bash
docker build -t scanpy-pbmc3k:latest -f docker/Dockerfile .
nextflow run nextflow/main.nf -profile docker
```

Resume interrupted runs with `-resume`; change the Leiden resolution with
`--resolution 1.0`. The annotated object and the MultiQC report paths are
printed at the end of the run.

### 5. MultiQC report

Every step writes MultiQC custom content (`*_mqc.json`); the pipeline
aggregates it into `results_nextflow/multiqc/multiqc_report.html` — a single
page with the QC summary, top markers per cluster and the cell-type
composition bar plot. The report can also be generated ad hoc:

```bash
multiqc results_nextflow --config nextflow/assets/multiqc_config.yml --outdir multiqc_out
```

## Parameters (`nextflow run ... --key value`)

| Param | Default | Description |
|---|---|---|
| `--input` | `data/pbmc3k_raw.h5ad` | Raw expression matrix |
| `--outdir` | `results_nextflow` | Published results root |
| `--resolution` | `0.8` | Leiden clustering resolution |
| `--python` | `python3` | Python interpreter (standard profile) |
| `--multiqc` | `multiqc` | MultiQC executable (standard profile) |
| `--container` | `scanpy-pbmc3k:latest` | Docker image (docker profile) |

## Outputs

`results/` (script & notebook) and `results_nextflow/<step>/` (pipeline):

* `objects/*.h5ad` — intermediate objects (qc → normalize → reduce → cluster → **annotate**)
* `tables/` — `qc_metrics.tsv`, `hvg_genes.tsv`, `marker_genes.tsv`,
  `celltype_annotation.tsv`, `celltype_proportions.tsv`, `*_mqc.json` (MultiQC)
* `figures/` — QC violins, HVG dispersion, PCA variance, UMAP (leiden /
  cell type / total counts), marker heatmap, dotplot

## Results at a glance

After QC (2,700 → **2,638 cells**, 2.3% removed) and Leiden clustering at
resolution 0.8, the data resolves into the 8 canonical PBMC populations:

| Cell type | Cells | Fraction |
|---|---:|---:|
| CD4 T cells | 1,108 | 42.0% |
| CD14+ (classical) monocytes | 471 | 17.9% |
| CD8 T cells | 345 | 13.1% |
| B cells | 344 | 13.0% |
| FCGR3A+ (non-classical) monocytes | 169 | 6.4% |
| NK cells | 154 | 5.8% |
| Dendritic cells | 35 | 1.3% |
| Platelets (contaminating) | 12 | 0.5% |

**Biological interpretation (short):** the recovered composition matches the
expected PBMC profile of a healthy donor — T cells dominate (~55%), followed by
monocytes (~24% combined), B cells and NK cells, with rare dendritic cells.
Each population expresses its canonical markers (CD3D/CD8A/NKG7/MS4A1/CD14/
FCGR3A/FCER1A/PPBP), validating the clustering and annotation. The 12-cell
platelet cluster is a well-known technical contaminant of droplet scRNA-seq.
The resolution trade-off is visible too: at 0.5 the rare DCs merge into the
monocyte cluster; 0.8 separates them. A fuller discussion, including caveats
(doublet detection, reference-based annotation), is in the notebook.

## Reproducibility

* The notebook and script share one codebase (`analysis/pbmc3k_scanpy.py`), so
  they cannot drift apart.
* Pinned dependencies in `docker/requirements.txt` (Docker image) and
  `environment.yml` (conda).
* The executed notebook prints the exact session environment
  (`session_info`).
* Nextflow's `-resume` gives step-level caching; the Docker profile isolates
  the environment.
* Dataset source: 10x Genomics [3k PBMCs from a Healthy Donor](https://www.10xgenomics.com/datasets/3-k-pbm-cells-from-a-healthy-donor-v-1-1-1-1-1),
  fetched via `sc.datasets.pbmc3k()`.
